Each JSON link opens a plain oracle.request input body. Run npm run validate offline or npm run check for free API screening. Full-body rejections, draft checks and non-blocking service suggestions are recorded separately. Screening is a sample and does not establish a signed answer. Do not pay for bodies 11–15, 21–25 or 29–30: the current chain recipes cannot attest their required types; see the README for live mismatch evidence.
